# Лёгкие на подъём

Рабочий MVP дыхательной 2D-игры для детей 5–10 лет и кабинета специалиста. Шарик управляется выдохом через микрофон браузера: спокойный выдох поднимает персонажа, пауза опускает его. Сессии превращаются в понятные агрегированные показатели.

> **Медицинский статус:** проект не является медицинским изделием, не ставит диагноз и не заменяет решение специалиста. Детекция выдоха, пороги качества и автоматические сводки **требуют валидации** на репрезентативных данных до клинического применения.

## Что входит в MVP

### Игра ребёнка

- вход по короткому псевдонимному коду без ФИО;
- калибровка: фоновая тишина + персональный спокойный выдох;
- анализ производных аудиопризнаков непосредственно в браузере;
- управление шариком выдохом, облака с монетами, без препятствий и проигрыша;
- мягкая техническая пауза при постороннем звуке: таймер стоит, прогресс и монеты сохраняются;
- позитивный экран результата без «Game Over» и штрафов;
- короткие звуковые сигналы; голосовая озвучка убрана, инструкции только текстом;
- магазин скинов за игровые монеты;
- сохранение длительности, циклов, силы, качества и игрового результата;
- демо-управление кнопкой/пробелом, если микрофон недоступен. Демо не влияет на показатели и баланс.

### Кабинет специалиста

- список пациентов и автоматическая недельная сводка;
- регулярность, пропуски, правильность, средний выдох и выполнение циклов;
- восьминедельные графики динамики;
- таблица сессий с фильтрами по периоду и режиму;
- CSV-экспорт текущей выборки;
- объяснение событий аудиопроверки;
- текстовая автоматическая сводка с явной пометкой «требует валидации».

### Улучшение №1 после MVP

Добавлена PWA-оболочка: manifest, иконки, предложение установки и offline-кэш статического интерфейса. Ответы `/api/*` намеренно не кэшируются service worker, чтобы медицински чувствительные агрегаты не оставались в offline-кэше приложения.

## Быстрый старт

Нужен **Node.js 22.5+** (используется встроенный `node:sqlite`).

```bash
npm install
npm run dev
```

- Web: <http://localhost:5173>
- API: <http://localhost:3001>
- Vite проксирует `/api` в локальный API.

Для микрофона браузеру нужен secure context: `localhost` или HTTPS. При первом запуске создаётся локальная БД `data/legkie.sqlite` и безопасные демоданные.

### Демо-доступ

| Роль | Доступ |
|---|---|
| Ребёнок | `ВЕТЕР7`, `ЗВЕЗДА` или `РАДУГА` |
| Специалист | кнопка «Войти в демо-кабинет» |

## Команды

```bash
npm run dev       # web + API в watch-режиме
npm run build     # проверка типов + production-сборка
npm start         # API и собранный dist на одном порту
npm test          # тесты Vitest
npm run lint      # ESLint
npm run check     # lint + test + build
```

После `npm run build` команда `npm start` раздаёт клиент и API одним Express-процессом на `PORT` (по умолчанию 3001).

## Архитектура

```text
Микрофон
  └─ Web Audio API (оперативный буфер)
      └─ RMS / ZCR / centroid / flatness / crest factor
          └─ персональный классификатор в браузере
              ├─ управление игрой
              └─ агрегаты сессии ──POST /api/sessions──> SQLite

React PWA ── /api ──> Express + Zod ──> SQLite
    ├─ интерфейс ребёнка
    └─ кабинет специалиста
```

- `src/audio` — извлечение признаков и объяснимый классификатор;
- `src/game` — чистая функция игровой физики;
- `src/pages` — два пользовательских контура;
- `server/db.ts` — схема, демоданные и запросы SQLite;
- `server/analytics.ts` — расчёт врачебных показателей;
- `tests` — классификатор, физика, аналитика и PWA-политика;
- `docs/ARCHITECTURE.md` — потоки данных и API;
- `docs/AUDIO_AND_VALIDATION.md` — ограничения детекции и план валидации.

## Приватность

**Сырое аудио не создаётся, не хранится и не передаётся.** Проект не использует `MediaRecorder`. `getUserMedia` подключается к `AnalyserNode`; временные массивы перезаписываются при следующем анализе и не покидают вкладку.

На API передаются:

- агрегированный профиль калибровки (RMS, ZCR, центроид, плоскостность, качество);
- итоговые метрики сессии;
- игровые результаты.

Для реального внедрения дополнительно нужны: DPIA/оценка применимого законодательства, полноценная аутентификация, шифрование и управление сроками хранения, аудит доступа, согласия законных представителей и организационная модель инцидентов.

## Текущие ограничения

- эвристический классификатор не обучен на детском клиническом датасете и **требует валидации**;
- крик, плач, кашель и бытовой шум различаются приближённо;
- демо-вход врача не является production-аутентификацией;
- SQLite и локальный deployment предназначены для MVP;
- автоматическая сводка сейчас шаблонная, а не нейросетевая;
- браузерные политики iOS/Android могут по-разному управлять микрофоном и установкой PWA.

## Лицензирование и данные

Демопрофили синтетические. Реальные ФИО и аудиофайлы в репозитории отсутствуют. Перед использованием с пациентами необходимо определить лицензию, владельца данных и регламент клинической валидации.
